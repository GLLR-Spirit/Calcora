Privacy information

This page explains the current, general data practices of Calcora. Individual tools may have additional notices where their behaviour differs.

Last reviewed: 30 October 2026

Calculations in your browser

The basic calculators are designed to process the values you enter in your browser. They do not require you to create a Calcora account.

Local browser storage

Some tools save preferences or study information on your device using browser storage. Depending on the tool, this may include language or theme preferences, study plans, progress, notes or saved items. This information is generally available only in the browser profile where it was saved.

Clearing or moving your data

Clearing site data or browser storage may erase locally saved information. Use a tool's export or backup feature before clearing data or changing devices, when that feature is available. Keep exported backup files private.

Website hosting and network requests

The public website is hosted through GitHub Pages. Opening the site requires network requests to the hosting service. The hosting provider may process technical request information under its own policies. This notice does not claim that network requests are anonymous or that no technical logs exist.

External services and links

Some pages may link to third-party websites or load external resources. Those services have their own privacy practices. Check the relevant tool's notice before using any feature that sends information to an external service.

Information you should not enter

Do not enter passwords, payment details, government identifiers, private academic records or other sensitive personal information into Calcora. Public GitHub feedback issues should never contain private information.

Updates to this notice

This notice should be updated when the site's storage, analytics, advertising or external-service behaviour changes. Check this page periodically.
