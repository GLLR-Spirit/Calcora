# Architecture

HTML/CSS/JavaScript powers the static GitHub Pages website. React is a possible future frontend build. Node.js can be used for build tooling or an API. Python, PHP and Ruby require a separate server. SQL requires a database and secure API. GitHub Pages does not execute backend code. Do not create empty files in every language just to claim support.

Suggested data model: education level → country/institution profile → program/field → subject/module → calculator. Store grading scale, academic year, rule source and review date. Do not assume every Algerian university uses identical rules.
